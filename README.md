# 4院 日報 自動収集・集計システム

4つのクリニックが Talknote の院別ノートに毎日投稿する日報（本文＋添付Excel）を自動で収集し、日次・月次・年次で集計・分析するWebシステムです。

| 資料 | 内容 |
|---|---|
| [01_調査結果と設計提案](docs/private/01_調査結果と設計提案.md) | 接続方式の確認、4院の本文・Excelの構造、推奨構成、DB設計、画面案 |
| [02_設定・起動・運用手順](docs/02_設定・起動・運用手順.md) | セットアップ、起動、日常の運用、エラーからの復旧、本番稼働に必要な作業と費用 |
| [03_検証結果と未確定事項](docs/private/03_検証結果と未確定事項.md) | サンプルと実データの検証結果（分けて記載）、完了条件の状況、未確定事項 |
| [04_院別の項目定義と集計ルール](docs/04_院別の項目定義と集計ルール.md) | 指標の定義、院別の読み取り元、二重計上防止・集計のルール |

## すぐに使う

```bash
python -m app.cli serve --port 8100
```

起動したら `http://localhost:8100` を開きます。管理者でログインし、「設定」でTalknoteのログイン情報を登録して、「稼働状況」で接続テストを実行してください。

| コマンド | 内容 |
|---|---|
| `python -m app.cli run connection_test` | 接続テスト |
| `python -m app.cli run manual --start 2026-09-01 --end 2026-10-19` | 期間を指定して収集 |
| `python -m app.cli reparse --start … --end …` | 保存済みの原文・原本から再解析（Talknoteには接続しない） |
| `python -m app.cli status` | 稼働状況の表示 |
| `python -m pytest` | 自動テスト（サンプルデータ） |
