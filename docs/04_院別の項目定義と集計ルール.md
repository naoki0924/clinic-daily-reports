# 院別の項目定義と集計ルール

- 正本はDBの `parse_rule`（院×本文/Excel の版管理）です。初版は `app/rules/__init__.py` にあります。
- 管理画面の「設定 → 項目対応・読み取りルール」で変更でき、変更は新しい版として保存されます。
- この資料は 2026-10-19 時点の有効な版（本文：9ru v3・他院 v2、Excel：各院 v2）を説明します。

## 1. 指標の定義

| コード | 名称 | 手数料 | 内部取引 | 全院合計 | 備考 |
|---|---|---|---|---|---|
| sales_net | 売上（手数料抜き） | 抜き | 含む | **する** | 全院合計の基本指標 |
| sales_gross | 売上（手数料込み） | 込み | 含む | する | |
| sales_incl_cpc | 売上（CPC受託・手数料込） | 込み | 含む | しない | BiO本文の「●売上」 |
| sales_actual | 実売 | 抜き | 除く | しない | BiO本文の「●実売」 |
| receipt | 入金 | — | — | する | Excelの「入金合計」：現金＋クレジット等＋振込＋デポジット（大阪はクーポン手数料を控除） |
| receipt_excl_deposit | 入金（デポジット除く） | — | — | しない | 9ru本文の「入金」 |
| transfer / ar_new / offset | 振込／売掛（当日発生）／相殺 | — | — | する | 売掛の残高は日別に合算しない |
| deposit | デポジット | — | — | **しない** | 新規預りか利用額かが未確定（常に「暫定」） |
| payment / payment_count | 決済方法別の金額・件数 | — | — | しない | 区分：決済方法・市場 |
| cpc_amount / cpc_count | CPC受託の金額・件数 | — | 含む | しない | 内部取引の消去情報がないため連結しない |
| visitors_total / visitors_new / visitors_existing / visitors_segment | 来院者（院の報告値） | — | — | しない | 実人数・ユニーク患者数は算出しない |
| contracts / inquiries / inquiries_confirmed / retail_count | 契約／問い合わせ／確定／物販 | — | — | しない | |
| category_sales / category_count / category_visits / category_contracts | 施術カテゴリ別 | — | — | しない | 施術件数は来院者数とみなさない |
| insurance_* | 保険診療 | — | — | しない | PREVENTIONの本文 |

## 2. 院別の読み取り元

### CLINIC 9ru

| 指標 | 本文 | Excel（見出し） |
|---|---|---|
| sales_net | 【売上入金】「売上 ￥… ※手数料…」 | 「売上計 ※手数料抜」 |
| sales_gross | — | 「売上計 ※手数料込」 |
| receipt | — | 「入金計」（デポジット込みの数式） |
| receipt_excl_deposit | 【売上入金】「入金 ￥…」 | — |
| deposit / transfer | 【売上入金】「デポジット」「振込」 | 「デポジット 金券等」「振込」 |
| payment | 【入金内訳】「現金/クレジット/Wechatpay/… N件 ￥…」 | 「現金」「クレジット・アプリ決済 計」「WechatPay」「Alipay」 |
| ar_new | 【入金内訳】「売掛 N件 ￥…」 | 「売掛」 |
| visitors_new / contracts | 「新規N件/契約N件」 | — |
| visitors_total / visitors_segment | 「来客者合計人数 N名」と「…のお客様 N名」 | — |
| retail_count / inquiries | 【物販】【問合せ】 | — |
| category_sales / count | — | 国内売上・インバウンド売上 × カテゴリ × 売上/件数 |

- 対象日は本文1行目の「M月D日 曜日」で判定します（年は投稿日から補う）。
- 「【月間総集計】」以降は読みません。
- ファイル名「…20251205版」の日付は書式の版なので使いません。
- 入金の照合式：本文の入金（デポジット除く）＝【入金内訳】の合計（デポジット・売掛・相殺を除く）

### BiO STYLE CLINIC

| 指標 | 本文 | Excel |
|---|---|---|
| sales_incl_cpc / sales_actual / ar_new / receipt | ●売上／●実売／●売掛／●入金 | — ／ — ／「売掛」／「入金合計」 |
| sales_net / sales_gross | — | 「売上合計 ※手数料抜き」／「売上計 ※手数料込」 |
| cpc_amount / count | 〈グループ内CPC受託売掛〉「品目 ￥…/N件」 | CPC受託 × 品目 × 売上/件数 |
| payment | 〈一般〉〈AIMS/ITEC〉〈BTS〉〈再生美容〉〈インバウンド〉× 決済方法 | 「現金」「クレジット…計」 |
| inquiries | ＜区分＞（TEL）（メール）（来院）（LINE/国際部） | — |
| treatment_count | 【概要】N件 | — |
| 休診 | — | 「休診」欄 |

- 本文に日付がないため、ファイル名の保存日時・Excelの入力済み最終日・投稿日で対象日を判定します。
- ファイル名に「日報」を含む添付だけを読みます（領収書の添付は除外）。
- 旧書式（〜2025年10月）：「●」がなく、冒頭が「売上 ○円／入金 ○円／売掛 ○円」（10月は「売上(CPC受託+手数料込)」「売上（手数料差引）」も）。
  〈一般〉〈インバウンド〉の小見出しがある投稿を日報と判定します。売上→sales_incl_cpc、入金→receipt。
  冒頭の「売掛」はCPC受託の請求分を含み（本文−Excelの売掛＝CPC受託額を実データで確認）、Excelの売掛と定義が違うため
  別指標 ar_incl_cpc（売掛（CPC受託含む）・照合しない）として保存します。〈CPC受託〉〈AIMS〉〈ITEC〉の小見出しにも対応。
  「実売」は旧書式にないため「記載なし」です（0とはみなしません）。

| sales_gross | — | 「国内+インバウンド（手込）」 |
| payment / offset / deposit / transfer | 【入金内訳】 | 「現金」「クレジット…計」「相殺」「デポジット金」「振込」 |
| visitors_new / total / segment | 【新規来院】N名、来院者合計人数、ビジター・ゲスト・メンバー・年間パス・企業ドック | — |
| inquiries | 【問い合わせ】 | — |
| insurance_* | ★【保険診療 来院】【保険診療 売上】 | （未対応：Excelの保険列は列構成が複雑なため本文のみ） |

- 入金の照合式：本文の入金＝決済方法別＋振込＋デポジット（実データとExcelの数式で確認）

### BiO STYLE CLINIC大阪

| 指標 | 本文 | Excel |

| sales_gross | 【売上入金】「売上：￥…」（実データでExcelの手込と一致） | 「国内+インバウンド（手込）」 |
| sales_net | — | 「国内+インバウンド（手数料抜き）」 |

- 冒頭に「神戸」とある投稿は他院として除外します。
- 開院日は 2026-07-28 です。それより前の日は「開院前」とし、未提出に数えず、全院合計の「値のない院」にも含めません。
- シート名は「2026.10」形式です。

## 3. 集計ルール

1. **観測値と採用値**：出典（本文の行、Excelのセル）ごとに観測値を保存します。院×日×指標×区分ごとに採用値を1つだけ作り、集計は採用値だけを使います。
2. **採用の規則**

   | 状況 | 扱い |
   |---|---|
   | 本文とExcelが一致 | 確定 |
   | 片方だけに値がある | その値を採用 |
   | 両方に値があり異なる | 要確認（値は空。確認キューで選ぶ） |
   | 誤記の疑い・計算結果のない数式・後日の添付での変更・対象日の要確認・判定不能な複数投稿 | 要確認 |
   | 定義が未確認・デポジット・Excelの数式の結果が0で本文が「-」・当日のExcelがなく後日のExcelの値を使う | 暫定 |
   | 手動補正・採用値の選択 | 最優先（理由と履歴を保存） |

3. **同じ日の複数投稿**：冒頭3行に「訂正・修正・差し替え・再送」があれば訂正（置き換え）とします。本文の値がすべて同じなら再投稿（計上しない）、それ以外は要確認です。
4. **Excelの範囲**：対象日の行だけを読みます。月合計・予測・目標の行は計上に使わず、日別の合計との照合にだけ使います。後日の添付にある過去40日分は「変更の検知」に使います。当日の添付にExcelがない（または値が空欄の）日だけは、後日のExcelの値を「暫定」で採用します。
5. **月次・年次**：採用値（要確認を除く）を合計します。未提出・取得失敗・要確認・暫定の日がある場合は「暫定」と表示し、日数を示します。
6. **全院合計**：全院合計を出してよい指標（`cross_clinic_sum`）だけを合計し、区分のない値だけを使います。値のない院は画面に表示します。
7. **比較**：前日、前週同曜日、前月・前年同月（進行中の期間は同じ経過日数で比較）を出します。比較期間のデータが半分未満なら「データ不足」と表示します。
8. **率**：分子と分母の両方がある日だけについて、それぞれを合計してから割ります。分母0は算出不可です。「契約÷新規来院」は「新規契約率（院報告値ベース）」と呼び、成約率とは呼びません。
9. **日の状態**：開院日より前（開院前）、日報あり（要確認がなければ提出済み）、日報で休診、設定の定休日・休診日、Excelの休診欄、取得失敗、未到来、未提出、の順に判定します。
